# Selenium Login Automation Project

This project demonstrates automation testing of a login functionality using Selenium WebDriver with Java and TestNG.

## 🚀 Features

* Automated valid login scenario
* Used Selenium WebDriver for browser automation
* Implemented assertions to validate login success
* Used locators like ID and CSS Selector

## 🛠️ Technologies Used

* Java
* Selenium WebDriver
* TestNG
* Maven

## 🧪 Test Scenario

1. Open login page
2. Enter valid username and password
3. Click login button
4. Verify successful login message

## ▶️ How to Run

* Open project in IntelliJ IDEA
* Run the `LoginTest` class
* Chrome browser will open and execute the test
